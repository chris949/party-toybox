# パーティトイボックス

**通話でわいわい、9つのゲーム**

友人同士で通話をつなぎながら、各自のスマホやPCのブラウザで遊ぶ、オンラインのパーティーゲーム集です（元の名前は「ティアリストウォーズ」。v0.20 で名前とURLを変えました。前のURL `…/tier-list-wars/` は開けません。端末に保存したお題や名前は、そのまま引き継がれます）。

| ゲーム | ひとこと |
|---|---|
| ティアリスト | みんなが作ったお題を誰かが自分の好みで並べ、ほかの全員がその順位を当てる。**あの人の「順位」、当てられる？** |
| セレクトファイブ | 正解とダミーが混ざった選択肢から、正解を5つ選ぶ |
| 運命の二者択一 | 2択クイズのサバイバル。不正解の側は床が抜ける |
| ハイカー575 | みんなで1文字ずつ書いて、五・七・五を作る |
| ブラインドブラフ | 自分のカードだけ見えないトランプ遊び。通話でだまし合う |
| ワードブーケ | 配られた言葉のカードを並べて、お題に合うひとことを作る。親がいちばん刺さったものを選ぶ |
| まぎれろ！ | 同じ見た目のキャラクターが大勢うろうろする舞台で、1体だけ人が動かす。どれが人かを当てる |
| 爆弾まわし | いつ爆発するか分からない爆弾を回す。回ってきたら、自分のお題の正解を1つ当てて渡す |
| スタンプ伝言 | 絵と言葉の伝言ゲーム。スタンプを置いて絵にするので、絵が苦手でも遊べる |

ホストがロビーで「モード」を選ぶと、遊ぶゲームが変わります。

▶ **あそぶ：https://chris949.github.io/party-toybox/**

インストールもアカウント登録も要りません。サーバーを持たない P2P 方式なので、運営費もかかりません。

## あそびかた

### 準備（各自、遊ぶ前に）

1. 上のURLを開いて名前を入れる
2. 「お題の設定」でお題を作る
   - お題1つにつき選択肢は5〜50個。「出題数」（5〜10個）を決めておくと、ゲームではその数だけランダムに出ます。多めに作っておくと、毎回違う組み合わせで遊べます
   - 例）「好きな野菜は？」→ じゃがいも／にんじん／たまねぎ／キャベツ／トマト
   - チェックを入れたお題が、次のゲームに持っていくお題になります
   - 最初からサンプルのお題が10個入っているので、作らなくても遊べます。ただし自作のお題が優先して配られるので、作った方が盛り上がります

### ティアリストの流れ（2〜10人）

1. **部屋を作る**：ホスト役が「部屋を作る」を押し、表示された6文字の部屋コード（または招待リンク）をみんなに送る
2. **集まる**：ほかの人は部屋コードを入れて「参加」。そろったらホストが「ゲーム開始」
   - ホストはロビーで「出題方式」を選べます。**全部からランダム**（初期値）か、**作成者ごとに1つずつ**（自作のお題を持ってきた人のお題は必ず1つ出る）
3. **準備フェーズ**：みんなのお題が1人1つずつ配られるので、**自分の好み**で1位から順に並べる（タップでも、ドラッグでも並べられます）
4. **予想フェーズ**：「〇〇さんの『お題』の順位は？」を、本人以外の全員が予想する
   - 並べる時間は、ホストがロビーで**30秒／60秒（初期値）／90秒**から選べます。並べ終えていれば、決定を押し忘れても提出されます。並べ終えていないとき、準備フェーズは残りがランダムで埋まり、予想フェーズは未提出（0点）になります
   - 問題数は参加人数と同じです。配られたお題は全部出題されます
5. **答え合わせ**：正解が最下位から1位へ自動でめくられる。めくるたびに、全員の予想が当たったか外れたか分かる
6. 全員分のラウンドが終わったら最終結果。得点がいちばん高い人の勝ち

### ティアリストの得点

| | 点 |
|---|---|
| 順位が1つ一致するごと | +1 |
| 全部一致（パーフェクト） | さらに +3 |

### セレクトファイブ

ホストがロビーで「モード」を **セレクトファイブ** にすると遊べます。

- お題には、作った人が登録した**正解とダミー**が混ざって並びます。**正解だと思うものを5つ**選んでください
- 作った人は答えず、みんながダミーに引っかかるのを見守ります
- 答え合わせでは正解が1つずつめくられ、最後の正解と同時にダミーが明かされます
- 正解1つにつき+1点、5つ全部正解ならさらに+3点。ダミーを選んでも減点はありません
- お題は「お題の設定」の「セレクトファイブ」のタブで作ります（正解5個以上・ダミー1個以上。出す選択肢の数と、そのうちのダミーの数も決められます）。作らなくても、同梱のサンプル10個で遊べます

### 運命の二者択一

ホストがロビーで「モード」を **運命の二者択一** にすると遊べます。2択クイズのサバイバルです。

- 問題と、左右2つの答えが出ます。自分のキャラクターを**正しいと思う側へ動かして**ください（答えか床をタップ。キーボードは ← →）。みんなの位置は全員に見えます
- 締め切りの瞬間にいた側が答えになります。**不正解の側は床が抜けて脱落**。真ん中のまま動かなかった人も落ちます
- 最後の1人になるまで続けます。全員が不正解のときは、全員セーフでやり直し
- **ライフ**：落ちるたびに1つ減り、なくなったら脱落です（初期値は3。ホストがロビーで1〜3から選びます）
- **お立ち台**：全員が順番に、同じ回数だけ「出題者」としてお立ち台に立ちます（回数はホストがロビーで選びます）。その問題では動けず、自動でセーフ。自分の画面にだけ正解が光ります。自分の問題がない人には、サンプルが割り当てられます。生き残りが2人になったら、生き残りはお立ち台に立ちません
- 脱落した人は**ゴースト**になって動き回れます。わざと逆の側に集まって、生き残りを惑わせましょう
- 1問の制限時間は、ホストがロビーで 5／10／15秒から選びます
- 問題は「お題の設定」の「運命の二者択一」のタブで作れます（問題文・正解・不正解）。作った人は、自分の問題では自動でセーフ。セレクトファイブのお題も、正解とダミーを1つずつ抜いた2択として出ます（1つ作れば、毎回違う問題になります）。作らなくても、同梱のサンプルで遊べます
- キャラクターは、ホームかロビーで選べます（動物12種と人5種。3D表示では、アニメ調のデフォルメのキャラクターになります。2D表示の絵は、いまは仮の絵文字です）
- 舞台は **3D と 2D** を切り替えられます（舞台の右下のボタン。端末ごとに保存）。3D が重い端末では 2D にしてください

### ハイカー575

ホストがロビーで「モード」を **ハイカー575** にすると遊べます。みんなで1文字ずつ書いて、五・七・五の句を作ります。

- 1人に1枚、短冊が配られます。全員が同時に**ひらがなを1文字**書くと、短冊が隣の人に回ります。回ってきた短冊には、それまでの文字が全部見えています
- 遊び方は2つ。**お題持ち寄り**（上の五文字はお題。残りの12文字を書く）と、**17文字ぜんぶ**（何もないところから書く）
- 書き終わったら、1作品ずつ発表します。短冊の**担当者が、通話で読み上げて**ください。誰がどの文字を書いたかも色で出ます
- 担当者以外の全員が**★1〜5**を付けます。作品の点（★の平均×10）が、担当者の得点になります
- 時間切れの文字は、ランダムなひらがなで埋まります
- お題（ひらがな5文字）は「お題の設定」の「ハイカー575」のタブで足せます。作らなくても、同梱のサンプル20個で遊べます

### ブラインドブラフ

ホストがロビーで「モード」を **ブラインドブラフ** にすると遊べます。お題は使いません。

- 1人に1枚、1〜13の数字のカードが配られます。**自分のカードだけ見えず、ほかの全員のカードは見えます**
- 制限時間のあいだ、通話でしゃべってください。本当のことを言っても、嘘を言ってもかまいません
- 「**勝負**」か「**降りる**」を選びます。選んだら変えられません
- 降りると −1点。勝負して負けると −2点。勝負した中でいちばん強い人が、みんなの払った点をもらいます
- **いちばん強いカードなのに降りると、さらに −2点**
- 全員10点から始めて、8ラウンド。点が多い人の勝ちです
- 人数が少ないときは、ロビーで CPU を足せます

### ワードブーケ

ホストがロビーで「モード」を **ワードブーケ** にすると遊べます。

- 毎ラウンド、1人が**親**になります。お題（例：プロポーズの言葉）が出ます
- 親以外の全員に、**言葉のカード**が14枚配られます。カードと「つなぐ言葉」（は・が・を・！ など）をタップして並べ、お題に合うひとことを作ってください
- 欲しい言葉がないときは、1ラウンドに1回だけ、手札をまるごと引き直せます
- 出そろったら、親が**声に出して読み上げて**、いちばん刺さったものを1つ選びます。選ばれた人に1点。誰が作ったかは、最初から見えています
- 終わり方は「全員が親を1回」「3点先取」「5点先取」から選べます
- お題は「お題の設定」の「ワードブーケ」のタブで足せます。作らなくても、同梱のサンプル24個で遊べます。言葉のカード（約300語）は、同梱のものを使います
- 人数が少ないと選ぶ候補が少ないので、ロビーで CPU を足すのがおすすめです

### まぎれろ！

ホストがロビーで「モード」を **まぎれろ！** にすると遊べます。お題は使いません。

- 同じ見た目のキャラクターが、3Dの舞台を大勢うろうろします。**1体だけ、人（かくれる人）が動かしています**
- **かくれる人**：▼ が付いているのが自分です。床をタップすると、そこへ歩きます。時間内に、舞台に出る **ほし** を3つ集めてください。ほしの上にいる間だけ「ほしを取る」を押せます
- ほしを取った瞬間は、全員に見えます。ほかのキャラクターが集まるのを待ってから取るのがコツです
- **さがす人**：あやしい1体をタップして選びます。何度でも選び直せますが、**ほしを3つ集められたら、その場で発表**です（その時点で選んでいた1体で判定します）
- 当てた人に +2点。かくれた人は、**ほしを3つ集めきったときだけ**、だませた人数ぶんの点がもらえます
- 全員が1回ずつかくれたら終わりです
- かくれる時間（30／45／60秒）と、キャラクターの数（8／12／16体）は、ホストがロビーで選べます
- 人数が少ないときは、ロビーで CPU を足せます

### 爆弾まわし

ホストがロビーで「モード」を **爆弾まわし** にすると遊べます。お題は、**セレクトファイブのお題**（みんなが持ってきたものと、サンプル）を使います。

- 誰か1人が爆弾を持ちます。**いつ爆発するかは、誰にも分かりません**
- 1人に1つ、別々のお題が配られます。爆弾が回ってきたら、**自分のお題の正解を1つ当てて**、渡す相手のボタンを押します
- 答え方は、ホストがロビーで選びます
  - **選択式**：正解だと思う選択肢をタップします
  - **入力式**：正解だと思う選択肢の文字を、打ち込みます（ひらがなでも、カタカナでも通ります）
- はずれ（ダミー）を選ぶと、2秒間、操作できません。一度当てた正解は、もう使えません
- 持っている人のお題と選択肢は、全員に見えます。通話で教えるかどうかは、自由です
- 時間がたつほど、カチカチが速くなり、爆弾が激しく揺れ、画面が赤くなっていきます
- 爆発したとき、持っていた人以外の全員に1点。決めた回数（3／5／8回）だけ爆発したら終わりです
- 導火線の長さ（みじかめ／ふつう／ながめ）は、ホストがロビーで選べます
- 人数が少ないときは、ロビーで CPU を足せます

### スタンプ伝言

ホストがロビーで「モード」を **スタンプ伝言** にすると遊べます。お題は、同梱のもの（90個）を使います。

- 1人に1つ、お題の言葉が配られます。それを **スタンプ（絵文字）だけで絵にして**、隣の人に回します
- 絵は、下の一覧からスタンプを選んで、指で動かして作ります。大きさ・向きも変えられます（1枚に15個まで）
- 次の人は、絵だけを見て、**何を表しているかを言葉で答えます**。その次の人は、その言葉をまた絵にします
- 全部回ったら、紙を1枚ずつめくって、どう伝わったかをみんなで見ます
- 最後の答えが最初のお題と合っていたら、その紙に関わった全員に +1点（点はおまけです）
- 絵を作る時間（45／60／90秒）は、ホストがロビーで選べます
- 人数が少ないときは、ロビーで CPU を足せます（CPU の絵と答えは、でたらめです）

## 遊ぶ前に知っておいてほしいこと（P2Pならではの注意）

このゲームはサーバーを使わず、**ホスト（部屋を作った人）のブラウザが進行役**になって、参加者の端末同士が直接つながります。そのため、次の点に気をつけてください。

### ホストについて

- **ホストが退出・切断すると、部屋は解散します。** 回線が安定していて、途中で抜けない人がホストをしてください。PCがおすすめです
- **ホストはスマホの画面を消さないでください。** 画面が消えたりアプリを切り替えたりすると、ブラウザが通信を止めて部屋が落ちることがあります
- ホストのブラウザにはゲームの全情報（全員の回答）が集まります。友人同士で遊ぶ前提なので、ホストのズルは防いでいません

### 参加者について

- 通信が切れると「再接続中…」と出て、自動でつなぎ直します。15秒たってもつながらないときはホームに戻るので、**同じタブのまま**「参加」を押してください。部屋コードは入力済みになっていて、ゲーム中でも元の状態に戻れます（タブを閉じると別人扱いになり、ゲーム中は入れません）
- 切断に気づかれず、みんなが待ち続けてしまうことがあります。そのときはホストが「未提出の人を待たずに進める」を押してください
- ゲームが始まった後からは、新しい人は参加できません

### 音について

- BGM と効果音が鳴ります。右上の 🔊 を押すと「BGM＋効果音 → 効果音だけ → 音なし」と切り替わります
- ホームの「音の設定」で、BGM・効果音の音量と、場面ごと（ロビー／並び替え／答え合わせ／最終結果）の曲を変えられます。自分の端末の音楽ファイルを選ぶと、あなたの画面でだけその曲が流れます（他の人には送りません）
- スピーカーで鳴らすと、通話のマイクに音が入ることがあります。気になる人はイヤホンを使うか、音を切ってください

### つながらないとき

- まず全員が同じURLを開いているか確認してください
- 会社や学校のネットワーク、一部のモバイル回線やVPNでは、端末同士の接続が制限されていてつながらないことがあります。その場合は自宅のWi-Fiやテザリングに切り替えて試してください
- 接続の仲介には、PeerJS の無料公開サーバーを使っています。このサーバーが止まっているときは遊べません（時間をおいて試してください）

## プライバシーとセキュリティ

- **参加者同士には、互いのIPアドレスが見えます。** P2P（端末同士の直接接続）の仕組み上、避けられません。知らない人とは遊ばないでください
- ゲームの通信は暗号化されています。直接つながらないときは PeerJS の中継サーバーを経由しますが、中身は読まれません
- 名前とお題は、**自分のブラウザの中にだけ**保存されます。どこかのサーバーに送られることはありません。別の端末やブラウザには引き継がれません
- 部屋コードを知らない人は部屋に入れません。もし知らない人が入ってきたら、ホストがロビーで ✕ を押して追い出せます
- 名前やお題はほかの参加者に表示されます。本名や個人情報は入れないことをおすすめします

詳しい対策内容は [docs/spec.md の 7.5](docs/spec.md) にまとめています。

## 開発者向け

React ＋ Vite ＋ TypeScript で作っています。構成と方針は [docs/architecture.md](docs/architecture.md) を見てください。

### 構成

| 場所 | 内容 |
|---|---|
| `src/core/` | どのモードでも共通のルール（部屋・参加・開始・CPU の参加者・見せる情報の共通部分）。画面も通信も使わない |
| `src/modes/<モード>/` | モードごとのフォルダ（`tier` ティアリスト／`five` セレクトファイブ／`fate` 運命の二者択一／`haiku` ハイカー575／`bluff` ブラインドブラフ／`bouquet` ワードブーケ／`blend` まぎれろ！／`bomb` 爆弾まわし／`relay` スタンプ伝言）。**仕様（`README.md`）**、ルール、お題の形、お題の作成画面、ロビーの設定、ゲーム画面、スタイルが入っている |
| `src/net/` | P2P 通信（PeerJS、見張り、自動再接続、CPU の参加者） |
| `src/app/` `src/ui/` | 画面の枠（ホーム・お題の設定・ルーム）と、共通の画面部品 |
| `src/audio/` `src/storage/` `src/styles/` | 音、端末への保存、共通のデザイン |
| `tests/` | ルールの自動テストと、CPU同士のシミュレーション |
| `e2e/` | 画面の通しテスト（Playwright。モードごとに1ファイル） |
| `docs/` | 共通の仕様書（`spec.md`）、技術構成、バックログ、テスト記録。**モードごとの仕様は、各モードのフォルダの `README.md`** |
| `CLAUDE.md` | 作業の決まり（仕様を先に直す、PR で入れる、など） |
| `legacy/v0.8.0.html` | 作り直す前の版（参照用。公開はされない） |

### 手元で動かす

```bash
npm install
npm run dev
```

表示された URL（http://localhost:5173/ など）を開きます。URL の末尾に `?dev` を付けると、2人から開始できます（動作確認用）。同じブラウザでもタブごとに別の参加者になるので、タブを複数開けば1人で通しで試せます。`?dev&bots=9` のように付けて部屋を作ると、CPU の参加者が入ります（最大9人。「運命の二者択一」「ハイカー575」「ブラインドブラフ」で動きます）。`?dev` のときは、開発者ツールから `__tlw.store`（画面の状態）と `__tlw.session`（通信）を触れます。

```bash
npm test
```

ルールの自動テストと、300ゲームのシミュレーションが走ります。

```bash
npm run build && npm run e2e
```

画面の通しテスト（ブラウザ2つで1ゲーム遊ぶ）が走ります。初回は `npx playwright install chromium` が必要です。

依存ライブラリの更新とセキュリティの運用は [docs/dependency-policy.md](docs/dependency-policy.md) にまとめています。

### 進め方

1. 改善したいことは、まず `docs/backlog.md` に書き出す
2. 実装する前に `docs/spec.md` を更新して合意する
3. 1回の変更は1テーマ。実装したらテストプレイで確かめ、結果を `docs/playtest-log.md` に記録する

### 公開

`main` ブランチに push すると、GitHub Actions がビルド → GitHub Pages への公開を行います（1分ほど）。テスト（型チェック・ルールのテスト・画面の通しテスト・`npm audit`）は PR のときに走り、通らないとマージできません。公開のときはテストを走らせないので、PR を通さずに直接 push したものはテストなしで公開されます。

### 曲と効果音を同梱する

1. 曲は `public/audio/bgm/`、効果音は `public/audio/se/` にファイルを置く
2. `public/audio/manifest.json` にパスを書く（例：`"bgm": { "lobby": "bgm/lobby.mp3" }`）。場面は `lobby`・`pick`・`reveal`・`result`、効果音は `click`・`start`・`pop`・`tick`・`drumroll`・`fanfare`・`perfect`
3. 出典と利用規約を [docs/credits.md](docs/credits.md) に書く

書いていないものは、内蔵の音で鳴ります。BGM は `src/audio/snes/songs.ts` に楽譜として書いたスーファミ風のオリジナル曲で、`npm run dev` のあと `/bgm-preview.html` で試聴できます。楽譜の書き方は `src/audio/snes/engine.ts` の先頭にあります。**公開リポジトリに入るので、再配布してよい音源だけを置いてください。**

公開するたびに `package.json` の `version` を上げてください。ホーム右上に表示され（マウスを載せるとコミットのIDも出ます）、ホストと違う版の参加者がいるとロビーで警告が出ます。
