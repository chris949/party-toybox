# パーティトイボックス

**通話でわいわい、9つのゲーム**

友人同士で通話をつなぎながら、各自のスマホやPCのブラウザで遊ぶ、オンラインのパーティーゲーム集です。

▶ **あそぶ：https://chris949.github.io/party-toybox/**

- インストールも、アカウント登録も要りません
- 2〜10人。1人が部屋を作り、部屋コードか招待リンクを送るだけ
- サーバーを持たない P2P 方式です。部屋を作った人（ホスト）のブラウザが、進行役になります

## ゲーム

ホストがロビーで「モード」を選ぶと、遊ぶゲームが変わります。遊び方と決まりの詳細は、各ゲームのページにあります。

| ゲーム | ひとこと |
|---|---|
| [ティアリスト](src/modes/tier/README.md) | みんなが作ったお題を、誰かが自分の好みで並べ、ほかの全員がその順位を当てるゲーム。**あの人の「順位」、当てられる？** |
| [セレクトファイブ](src/modes/five/README.md) | 正解とダミーが混ざった選択肢から、正解を5つ選ぶクイズ。 |
| [運命の二者択一](src/modes/fate/README.md) | 2択クイズのサバイバル。不正解の側は、床が抜ける。 |
| [ハイカー575](src/modes/haiku/README.md) | みんなで1文字ずつ書いて回し、五・七・五を作るゲーム。 |
| [ブラインドブラフ](src/modes/bluff/README.md) | 自分のカードだけ見えないトランプ遊び。通話でだまし合う。 |
| [ワードブーケ](src/modes/bouquet/README.md) | 配られた言葉のカードを並べて、お題に合うひとことを作るゲーム。親が、いちばん刺さったものを選ぶ。 |
| [まぎれろ！](src/modes/blend/README.md) | 同じ見た目のキャラクターが大勢うろうろする舞台で、1体だけ人が動かす。どれが人かを当てるゲーム。 |
| [爆弾まわし](src/modes/bomb/README.md) | いつ爆発するか分からない爆弾を回すゲーム。回ってきたら、自分のお題の正解を1つ当てて渡す。 |
| [スタンプ伝言](src/modes/relay/README.md) | 絵と言葉の伝言ゲーム。スタンプを置いて絵にするので、絵が苦手でも遊べる。 |
