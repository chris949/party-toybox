# 遊ぶ前に（あそぶ人向け）

パーティトイボックスを遊ぶ人が、最初に知っておくとよいこと。ゲームごとの遊び方は、[README の一覧](../README.md)から各ゲームのページへ。

## 準備と、部屋の集まり方

1. 全員が https://chris949.github.io/party-toybox/ を開いて、名前を入れる（インストールも、アカウント登録も要りません）
2. 通話をつなぐ（通話の機能は付いていません。いつも使っているものでどうぞ）
3. 1人が「部屋を作る（ホスト）」を押し、出てきた6文字の部屋コードか、招待リンクを、みんなに送る
4. ほかの人は、部屋コードを入れて「参加」
5. ホストが、ロビーで遊ぶゲーム（モード）を選んで「ゲーム開始」。選んだゲームのあそびかたが、全員の画面に出ます
   - 人数は2〜10人。足りないときは、CPU を足せるゲームもあります
   - ゲーム中は、右上の「？」で、あそびかたをいつでも開けます

### お題

- ゲームによっては、みんなが作った「お題」を使います。ホームの「お題の設定」で作り、持っていくものにチェックを入れます
- 作らなくても、同梱のサンプルで遊べます。自分たちで作ったほうが盛り上がります
- 部屋に入ったあとでも、ロビーの「お題を選ぶ・編集する」から直せます

## 知っておいてほしいこと（P2Pならではの注意）

このゲームはサーバーを使わず、**ホスト（部屋を作った人）のブラウザが進行役**になって、参加者の端末同士が直接つながります。そのため、次の点に気をつけてください。

### ホストについて

- **ホストが退出・切断すると、部屋は解散します。** 回線が安定していて、途中で抜けない人がホストをしてください。PCがおすすめです
- **ホストはスマホの画面を消さないでください。** 画面が消えたりアプリを切り替えたりすると、ブラウザが通信を止めて部屋が落ちることがあります
- ホストのブラウザにはゲームの全情報（全員の回答）が集まります。友人同士で遊ぶ前提なので、ホストのズルは防いでいません

### 参加者について

- 通信が切れると「再接続中…」と出て、自動でつなぎ直します。15秒たってもつながらないときはホームに戻るので、**同じタブのまま**「参加」を押してください。部屋コードは入力済みになっていて、ゲーム中でも元の状態に戻れます（タブを閉じると別人扱いになり、ゲーム中は入れません）
- 切断に気づかれず、みんなが待ち続けてしまうことがあります。そのときはホストが「未提出の人を待たずに進める」を押してください
- ゲームが始まった後からは、新しい人は参加できません

### 音について

- BGM と効果音が鳴ります。右上の 🔊 を押すと「BGM＋効果音 → 効果音だけ → 音なし」と切り替わります
- ホームの「音の設定」で、BGM・効果音の音量と、場面ごと（ロビー／並び替え／答え合わせ／最終結果）の曲を変えられます。自分の端末の音楽ファイルを選ぶと、あなたの画面でだけその曲が流れます（他の人には送りません）
- スピーカーで鳴らすと、通話のマイクに音が入ることがあります。気になる人はイヤホンを使うか、音を切ってください

### つながらないとき

- まず全員が同じURLを開いているか確認してください
- 会社や学校のネットワーク、一部のモバイル回線やVPNでは、端末同士の接続が制限されていてつながらないことがあります。その場合は自宅のWi-Fiやテザリングに切り替えて試してください
- 接続の仲介には、PeerJS の無料公開サーバーを使っています。このサーバーが止まっているときは遊べません（時間をおいて試してください）

## プライバシーとセキュリティ

- **参加者同士には、互いのIPアドレスが見えます。** P2P（端末同士の直接接続）の仕組み上、避けられません。知らない人とは遊ばないでください
- ゲームの通信は暗号化されています。直接つながらないときは PeerJS の中継サーバーを経由しますが、中身は読まれません
- 名前とお題は、**自分のブラウザの中にだけ**保存されます。どこかのサーバーに送られることはありません。別の端末やブラウザには引き継がれません
- 部屋コードを知らない人は部屋に入れません。もし知らない人が入ってきたら、ホストがロビーで ✕ を押して追い出せます
- 名前やお題はほかの参加者に表示されます。本名や個人情報は入れないことをおすすめします

詳しい対策内容は [spec.md の 7.5](spec.md) にまとめています。
