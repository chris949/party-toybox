- 遊んでいる間は説明や助言をしない。困っていても、まずは黙って見る（どうしても進まないときだけ助ける。助けたら記録する）

### 結果

**見たこと（事実）**
- 反応は良かった（ホストの所感）
- 予想フェーズで、並べ終わっても「決定」が押せず、進まなくなった人がいた。開発者ツールは見ておらず、エラーの有無は不明。切断→復帰を試したかは未確認

**参加者の感想（要望）**
- お題の選択肢をたくさん作っておき、その中から何個ランダムに出すかを選べるようにしたい。そうなれば選択肢の上限（10個）は無くしてもいい
- BGM がほしい
- 選択肢はドラッグ＆ドロップで並べ替えたい
- 制限時間があってもいい。選ぶのは30秒くらいがテンポよさそう

**解釈**
- 「決定が押せない」は、予想フェーズで起きている。予想中は通話アプリなどに切り替えやすく、スマホのブラウザが裏に回ると通信が切れる。参加者側が切断に気づけず、送ったつもりの予想がホストに届いていない可能性が高い（コードを読んだ切り分けの結果。再現はできていない）
- 制限時間の要望は、待ち時間（Q3）に不満があったことを示している
- 選択肢を多めに作ってランダムに出す要望は、同じお題で何度も遊べるようにしたい（「もう1回」につながる）という声と読める

**分類**

| 内容 | 種類 | バックログ追加 |
|---|---|---|
| 予想フェーズで決定が押せず進まない | 不具合 | #13 |
| 出題数を選べる・選択肢の上限撤廃 | 設計の変更 | #14 |
| 制限時間30秒 | 設計の変更 | #15 |
| BGM・効果音 | 見た目（演出） | #16 |
| ドラッグ＆ドロップで並べ替え | 見た目（操作感） | #17 |

**次に試す仮説**
- 制限時間30秒を入れると、待ち時間の不満が消え、テンポよく進む（待たされた場面が出ない）
