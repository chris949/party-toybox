# バックログ

やりたいこと（UI/UX の改善・仕様の追加や変更・不具合）を全部ここに書き出す。思いついたらまず追加し、すぐには実装しない。

## 運用ルール

1. 思いついたら「未整理」に1行で追加する（良し悪しはこの時点では判断しない）
2. 整理するときに、種類・優先度・柱との関係をつける
3. 実装するときは、仕様書（`spec.md`）を先に更新して合意してから着手する
4. 1回の実装は1テーマ。終わったら「完了」へ移し、仕様書の変更履歴に記録する

- 種類: 仕様 ／ UI/UX ／ 不具合 ／ 技術
- 優先度: A（次にやる） ／ B（そのうち） ／ C（保留）
