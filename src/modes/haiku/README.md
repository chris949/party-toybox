## 12. モード：ハイカー575（v0.18。決定：2026-11-12）

壁打ちで決めた内容（2026-11-12）。**［提案］** と付けたところは、壁打ちで話していない細部を Claude が補ったもの。

### 12.1 概要

- 参加者みんなで、1文字ずつ書いて回し、五・七・五の句を作る。できた句を担当者が読み上げ、全員で採点する
- **盛り上がる瞬間**：託した続きが思わぬ方向へ行く（「『はな』って書いたのに『はなぢ』にされた！」）、たまに全員の意図が噛み合って名句ができる（「おお…」）、発表で誰がどの文字を書いたかが分かる（「ここで『ぬ』入れたの誰！」）
- 唸るような作品も、カオスな作品も、どちらも楽しむ。採点に部門は設けない（うまさとカオスを分けて縛らないため）

### 12.2 遊び方の種類（ホストがロビーで選ぶ）

| 種類 | 中身 |
|---|---|
| お題持ち寄り（初期値）［初期値は提案］ | 上の五文字は、持ち寄ったお題（または同梱のサンプル）。残りの12文字をみんなで書く |
| 17文字ぜんぶ | 何もないところから、17文字すべてをみんなで書く |

- 1文字の制限時間は、ホストがロビーで **10／15（初期値）／20秒** から選ぶ ［提案］

### 12.3 お題（上の五文字）

- 「お題の設定」に「ハイカー575」のタブを足す。1つのお題は、**ひらがな5文字**（例：ふるいけや）
- 同梱のサンプルを20個用意する。端末のストックには入れず、足りない分をホストが補う（10.3 と同じ扱い）
- 「お題持ち寄り」では、短冊1枚につきお題を1つ使う。**短冊の担当者が持ってきたお題**から1つ選び、持ってきていなければサンプルを使う。同じお題は、1ゲームに1回まで ［提案］

### 12.4 書く

- 短冊は、参加者と同じ枚数。1人が1枚の**担当者**になる（発表で読み上げる人。採点の点も担当者に入る）
- 全員が同時に、手元の短冊に**1文字**書く。全員が書き終わる（または時間切れになる）と、短冊が隣の人に回り、次の1文字を書く。これを、12回（お題持ち寄り）または17回（17文字ぜんぶ）繰り返す
- 手元の短冊は、それまでに書かれた文字が**全部見える**。ほかの短冊は、発表まで見えない
- 書けるのは**ひらがな1文字**（カタカナで打っても、ひらがなにする）。小さい「ゃ」「っ」や「ー」も、1マスに数える。厳密な五七五にはこだわらない ［提案］
- 時間切れ・切断中の人の分は、ランダムなひらがなで埋める。発表のときに、時間切れの文字だと分かるようにする ［提案］
- ホストは「未提出の人を待たずに進める」で先に進められる（今のモードと同じ）

### 12.5 発表と採点

1枚ずつ、ランダムな順に発表する。

| 順番 | 中身 |
|---|---|
| ① めくる | 五・七・五を1行ずつ、縦書きの短冊に自動で出す。ホストと担当者は「一気に出す」で飛ばせる |
| ② 読み上げ | 「〇〇さん、読み上げてください」と出す。担当者が、通話で声に出して読む |
| ③ 誰が書いたか | 1文字ごとに、書いた人の色を付けて見せる |
| ④ 採点 | 担当者以外の全員が、★1〜5 を付ける（締め切りまでは付け直せる）。全員が付けるか、30秒たつか、ホストが進めると締め切る ［時間は提案］ |
| ⑤ 結果 | 誰が何点を付けたかと、その作品の点を出す。ホストの「次の作品へ」で次へ |

- **作品の点 ＝ 付いた★の平均 × 10**（小数は四捨五入。平均4.3なら43点）。担当者の得点になる。合計ではなく平均にするのは、時間切れで採点しなかった人がいても不公平にならないようにするため ［提案］
- 担当者は、自分の作品には採点しない

### 12.6 最終結果

- 得点の高い順に順位を出す（今のモードと同じ）。1位の人の画面に紙吹雪
- できた作品を、点の高い順に全部並べる（あとで見返したり、画面を保存したりできるように） ［提案］

### 12.7 そのほか

- 人数・切断・部屋の決まりは、今のモードと同じ
- 動作確認用の CPU（`?dev&bots=9`）は、このモードでも動く（ランダムなひらがなを書き、ランダムに採点する）
