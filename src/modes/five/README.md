# セレクトファイブ

正解とダミーが混ざった選択肢から、正解を5つ選ぶクイズ。

- 遊ぶ：https://chris949.github.io/party-toybox/ （ホストが、ロビーで「モード」を **セレクトファイブ** にする）
- ゲーム集ぜんたいの説明・遊ぶ前の注意：[README](../../../README.md)・[docs/guide.md](../../../docs/guide.md)

## あそびかた

- お題には、作った人が登録した**正解とダミー**が混ざって並びます。**正解だと思うものを5つ**選んでください
- 作った人は答えず、みんながダミーに引っかかるのを見守ります
- 答え合わせでは正解が1つずつめくられ、最後の正解と同時にダミーが明かされます
- 正解1つにつき+1点、5つ全部正解ならさらに+3点。ダミーを選んでも減点はありません
- お題は「お題の設定」の「セレクトファイブ」のタブで作ります（正解5個以上・ダミー1個以上。出す選択肢の数と、そのうちのダミーの数も決められます）。作らなくても、同梱のサンプル10個で遊べます

## 10. モード：セレクトファイブ

### 10.1 概要

- お題に対して、作者が登録した**正解とダミーを混ぜた選択肢**が並ぶ。答える人は、正解だと思うものを**ちょうど5つ**選ぶ
- **盛り上がる瞬間**：ダミーに引っかかる場面（「え、それダミーなの！？」「絶対正解だと思った…」）。主役はダミーを仕込んだ作者。答え合わせの締めくくりを、ダミーを明かす瞬間にする
- ダミーの出来に作者のセンスが出る（柱3）。全部当てたときの達成感（柱2）は、得点で味付けする

### 10.2 モードの選び方

- ホストがロビーで、モード（ティアリスト／セレクトファイブ）を選ぶ。出題方式・制限時間と同じ場所に置く。ゲーム開始まで何度でも変えられ、ロビーに戻っても前回の設定を引き継ぐ
- 1ゲームの中で遊ぶモードは1つだけ。ラウンドごとに混ぜない（ルール説明と画面の切り替えが増えて分かりにくいため）
- 遊んだ人の反応を見て、選び方を見直す（Q14）

### 10.3 お題の作成・編集

- お題のストックは、モードごとに分ける。「お題の設定」画面に、ティアリスト用とセレクトファイブ用のタブを設ける（中身の形が違うため）
- 1つのお題に登録するもの：

| 項目 | 範囲 | 理由 |
|---|---|---|
| お題 | 最大60文字 | 今のモードと同じ |
| 正解 | 5個以上（各最大40文字） | 5つ選ぶので、最低5個必要。正解とダミーは合わせて7個以上 |
| ダミー | 1個以上（各最大40文字） | ダミーがないと全部正解になってしまう |
| 出題する選択肢の数 | 7〜12個（初期値10） | 7より少ないと簡単すぎる。12より多いとスマホの画面に収まらない |
| うちダミーの数 | 1〜（選択肢の数−5）個（ただし登録したダミーの数まで）、または「おまかせ」（初期値は選択肢の数の半分） | 正解が5つを下回らないようにする。下限を1にしたのは、ダミーを1個だけ登録したお題も出せるようにするため（実装時に2から変更）。「おまかせ」は毎回ランダムに決めるので、答える人はダミーがいくつか分からない |

- 正解とダミーの合計は、最大50個（今のモードの選択肢の上限と同じ）
- 出題のたびに、登録した正解とダミーの中から、決めた数だけランダムに抜き出す。多めに登録しておくと、同じお題でも毎回違う組み合わせで遊べる
- 保存時のチェック：お題が空でない／正解が5個以上・ダミーが1個以上／正解とダミーを通して重複がない／決めた数を出せるだけの正解とダミーがある
- 同梱のサンプルのお題を10個用意する（ダミーの数はおまかせ）。サンプルは端末のストックには入れず、ホストが足りない分を補うときに使う
- 答える人には、ダミーの数を見せない（Q15。当面この形で遊び、反応を見て決める）

### 10.4 お題の配り方

- 今のモードと同じく、1人につき1つお題を配り、ラウンド数＝人数にする
- 自作のお題を優先する。出題方式（全部からランダム／作成者ごとに1つずつ）もそのまま使う
- 自作のお題が足りないときは、たくさん持ってきた人のお題から多めに出す。それでも足りなければ、同梱のサンプルで埋める（お題を作っていない人も、すぐに遊べるようにするため）

### 10.5 1ラウンドの流れ

1. **答える**：そのラウンドのお題の作者以外の全員が、同時に答える。制限時間はホストがロビーで選んだ長さ（4.4.4）
2. **答え合わせ**（10.7）
3. ホストの「次のラウンドへ」で次のお題へ。最後のラウンドのあとは最終結果へ（今のモードと同じ）

準備フェーズ（自分の順位を決める）はない。

### 10.6 画面

**答える人**
- 選択肢をカードで並べ、タップで選ぶ・外す。ドラッグは使わない（スマホで素早く操作でき、焦っていても押し間違えにくいため）
- 選んだ数を「3/5」のように出す。ちょうど5つ選ぶと、決定ボタンを押せる
- 決定したあとも、「選び直す」で取り消して選び直せる。選んだ5つはそのまま残る。答える人が全員そろった時点で答え合わせに進むので、それ以降は直せない（テストプレイで「一度決めると変えられない」という声があったため）
- 時間切れのときは、選んだ分だけで提出したことにする（0個なら未提出扱い）

**作者**
- 正解とダミーの印を付けた選択肢を見せる
- 誰が提出したかだけ表示し、誰が何を選んでいるかは答え合わせまで見せない（通話で口を滑らせて、答えがばれないようにするため）

### 10.7 答え合わせ

| 順番 | 中身 |
|---|---|
| ① 正解 | 正解を1つずつめくり、それを選んでいた人の名前を並べる（「当てた！」の積み重ね） |
| ② ダミー | **最後の正解をめくるのと同時に**、ダミーをまとめて明かす。引っかかった人の名前を「〇〇 に引っかかった！」と出す。誰も選ばなかったら「誰も引っかからなかった…」と出す（作者がいじられる場面） |
| ③ まとめ | 一人ずつ、当てた数・獲得点を出す（今のモードの 4.4.3 と同じ形） |

- 自動で進め、「残りを一気にめくる」ボタンを付ける（今のモードと同じく、押せるのはホストと作者）
- めくる間隔は今のモードと同じにして、テストプレイで調整する
- 当初は、正解のあとに「この中にダミーが○個…」と溜めてから、ダミーを1つずつめくる形だった。試したところ、演出がくどく、テンポが悪く感じたので、最後の正解と同時に明かす形に変えた（2026-11-11）

### 10.8 得点

| 項目 | 点 |
|---|---|
| 正解を1つ選ぶごと | +1 |
| 5つ全部正解（パーフェクト） | さらに +3 |
| ダミーを選ぶ | 減点なし |
| 作者 | 得点なし |

- 減点しないのは、勝ち負けを重くしないため（1.3）。ダミーを選んだときの痛みは、点ではなく答え合わせの演出で出す
- 未決：誰かがダミーを選ぶたびに、作者にも点を入れるか（Q16）
