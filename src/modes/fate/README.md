# 運命の二者択一

2択クイズのサバイバル。不正解の側は、床が抜ける。

- 遊ぶ：https://chris949.github.io/party-toybox/ （ホストが、ロビーで「モード」を **運命の二者択一** にする）
- ゲーム集ぜんたいの説明・遊ぶ前の注意：[README](../../../README.md)・[docs/guide.md](../../../docs/guide.md)

## あそびかた

2択クイズのサバイバルです。

- 問題と、左右2つの答えが出ます。自分のキャラクターを**正しいと思う側へ動かして**ください（答えか床をタップ。キーボードは ← →）。みんなの位置は全員に見えます
- 締め切りの瞬間にいた側が答えになります。**不正解の側は床が抜けて脱落**。真ん中のまま動かなかった人も落ちます
- 最後の1人になるまで続けます。全員が不正解のときは、全員セーフでやり直し
- **ライフ**：落ちるたびに1つ減り、なくなったら脱落です（初期値は3。ホストがロビーで1〜3から選びます）
- **お立ち台**：全員が順番に、同じ回数だけ「出題者」としてお立ち台に立ちます（回数はホストがロビーで選びます）。その問題では動けず、自動でセーフ。自分の画面にだけ正解が光ります。自分の問題がない人には、サンプルが割り当てられます。生き残りが2人になったら、生き残りはお立ち台に立ちません
- 脱落した人は**ゴースト**になって動き回れます。わざと逆の側に集まって、生き残りを惑わせましょう
- 1問の制限時間は、ホストがロビーで 5／10／15秒から選びます
- 問題は「お題の設定」の「運命の二者択一」のタブで作れます（問題文・正解・不正解）。作った人は、自分の問題では自動でセーフ。セレクトファイブのお題も、正解とダミーを1つずつ抜いた2択として出ます（1つ作れば、毎回違う問題になります）。作らなくても、同梱のサンプルで遊べます
- キャラクターは、ロビーで選べます（動物12種と人5種。3D表示では、アニメ調のデフォルメのキャラクターになります。2D表示の絵は、いまは仮の絵文字です）
- 舞台は **3D と 2D** を切り替えられます（舞台の右下のボタン。端末ごとに保存）。3D が重い端末では 2D にしてください

## 11. モード：運命の二者択一

### 11.1 概要

- 2択のクイズ。参加者は自分のキャラクターを画面の左右どちらかへ動かして答える。不正解の人は脱落し、最後の1人になるまで続ける
- **盛り上がる瞬間**：脱落の瞬間（「うわー、落ちた！」「道連れだ…」）。正解の発表と同時に、不正解の側の床が抜けて、そこにいた全員が一斉に落ちる。移動の駆け引き（「みんなそっち行くの！？」）は味付け
- ゲームというより演出が主役。事実のクイズとして作る（別のモードなので、人の好みを読む柱には縛られない）

### 11.2 モードの選び方と制限時間

- ホストがロビーで「モード」を「運命の二者択一」にする（10.2 と同じ）
- 1問の制限時間は、このモード専用にする。ホストがロビーで **5秒／10秒（初期値）／15秒** から選ぶ。今のモードの 30〜90秒は2択には長すぎるため
- 残りわずかの演出（4.4.4）は、残り3秒から出す ［提案］

### 11.3 問題の作成・編集

- 「お題の設定」に「運命の二者択一」のタブを足す（10.3 と同じく、モードごとにストックを分ける）
- 1問に登録するもの：問題文（最大60文字）・正解（最大40文字）・不正解（最大40文字）
- 同梱のサンプルを30問ほど用意する。端末のストックには入れず、足りない分をホストが補う（10.3 と同じ扱い）

### 11.4 問題の束

- **お立ち台のローテーション**：ゲームが始まったら、参加者をランダムな順に並べ、1人ずつ順番に「出題者」としてお立ち台に立つ問題を割り当てる。これを、ホストがロビーで選んだ回数（**お立ち台の回数：1／3（初期値）／5回**）だけ繰り返す
  - 自分が持ってきた問題がある人には、その問題を割り当てる（上の回数まで。超えた分は、そのゲームでは出さない）
  - 持ってきた問題がない人・回数に足りない人には、同梱のサンプルを割り当てる。**その人の画面でだけ、正解の側が光る**（ほかの人には見えない）。お立ち台に立つ回数を全員そろえて、問題を作っていない人が不利にならないようにするため
  - 全員の回数が終わったら、残りは同梱のサンプルを出す。このときは、誰もお立ち台に立たない
  - **生き残りが2人以下のときは、生き残りをお立ち台に立たせない**。ゴーストの番の問題か、サンプルだけを出す（生き残りに割り当てたサンプルは、割り当てを外して全員が答える問題にする。生き残りが持ってきた問題は、そのゲームでは後回しにする）。答える人が1人だけになると、不正解でも「全員不正解」で救済されて決着が付かないため
  - 理由：1人がたくさん問題を持ってくると、その人だけがお立ち台に立ち続けて遊べなくなる。順番と回数をそろえれば、問題を一気に作れるようにしても公平さが保てる
- **セレクトファイブのお題も、2択の問題として出す**。お題の正解から1つ、ダミーから1つをランダムに抜いて、「お題／正解／不正解」の1問にする。1つのお題から出すのは、1ゲームに1問まで
  - 理由：このモードは1問が数秒で終わり、問題の減りが速い。セレクトファイブのお題は「正解のリスト＋ダミーのリスト」なので、1つ登録してあれば何十通りもの2択になる（正解8個・ダミー6個なら48通り）。新しく作る手間もいらない
  - 持ってきたセレクトファイブのお題は「持ってきた問題」の側に、同梱のセレクトファイブのサンプル（10個）は「同梱のサンプル」の側に混ぜる
  - お題を持ってきた人は、その問題の「作った人」として扱う（自分の問題として、ローテーションで割り当てられる）
- 正解を左右どちらに出すかは、1問ごとにランダム
- **作った人は、自分の問題では自動でセーフ**（答えを知っているので、正解しても不公平になるため）。その問題のあいだは、左右の床のあいだにある**お立ち台**に立ち、左右には動けない（それまでは動けたが、「答えを知っている人が側を選べるのは微妙」という声があった。立っている側がヒントにも、だましにもなって、クイズとして濁るため）。ゴーストになっている人の番でも同じ。自分の問題でも、割り当てられたサンプルでも、お立ち台の人の画面には正解の側が光って見える

### 11.5 1問の流れ

1. **出題**：問題文と、左右の答えを出す。全員のキャラクターは真ん中に立った状態から始まる ［提案］
2. **移動**：締め切りまで、何度でも左右に動ける。全員の位置がリアルタイムで全員に見える
3. **締め切り**：その瞬間にいた側を答えとする。**真ん中のままの人は不正解**として扱う ［提案。動かない人が得をしないように］
4. **発表**：正解の側を光らせ、同時に不正解の側の床が開いて、そこにいたキャラクターが一斉に落ちる。落ちた人の名前を出す
   - **ライフ（残機）**：落ちるたびにライフが1つ減り、0になったら脱落する。ライフが残っている人は、次の問題でスタート台に戻ってくる。ライフの数は、ホストがロビーで **1／2／3（初期値）** から選ぶ（3なら、2回のミスまで許される）。名前のそばに ♥ で残りを出す
   - 理由：1回のミスで終わると、お立ち台が早く回ってきた人が有利になるなど、運の差が出やすい。数回のミスを許して、不公平感を減らす
5. 数秒おいて、自動で次の問題へ進む ［提案。テンポを優先し、ホストのボタンを待たない。ホストには「一時停止」を付ける］

### 11.6 終わり方と、全員が同じ結果のとき

| 場面 | 扱い |
|---|---|
| 生き残りが1人になった | その人の勝ちで終わる |
| 不正解だった | ライフが1つ減る。0になったら脱落してゴーストになる（11.5） |
| 全員が不正解 | 全員セーフにして、次の問題へ（「全員落ちたけど、今回は救済！」と出す）。ライフも減らない |
| 全員が正解 | そのまま次の問題へ |
| 問題がなくなっても、2人以上残っている | 残った全員の勝ち |

### 11.7 脱落した人（ゴースト）

- 脱落した人は**ゴースト**になり、次の問題からも左右に動き回れる
- 生き残っている人の画面にも、ゴーストは半透明で見える。正解の側に誘い込んだり、逆の側に集まって惑わせたりできる（「だまされるな！」）
- ゴーストは結果に関わらない。生き残っている人とはっきり見分けが付くようにする（半透明・ゴーストのポーズ）
- 答えそのもの（問題文や答えの文字）を見えなくする邪魔はしない。クイズとして不公平になって冷めるため
- 「もう少し邪魔ができてもよい」という声があり、強化はあとで考える（Q17）

### 11.8 キャラクター

| 項目 | 仕様 |
|---|---|
| 用意の仕方 | 画像生成で作った絵を、プリセットとして同梱する |
| 数 | 17体：動物12＋アニメ風の人5（ゆうしゃ・まほうつかい・にんじゃ・アイドル・かいぞく。どれもオリジナルで、実在の作品のキャラクターは使わない） |
| 選ぶ場所 | ホーム画面（名前の下）。このモードのロビーでも変えられる。端末に保存する |
| 同じキャラ | 重複してよい。名前と枠の色で見分ける。同じキャラクターの2人目からは、本体の色合いも変える（枠の色だけでは見分けにくかったため） |
| ポーズ | 「立ち」「移動中」「落ちる（驚き顔）」「ゴースト」の4つ |
| 絵の雰囲気 | 今の画面（水色のポップな色、太い黒の縁取り）に合わせた、丸っこい動物など |
| 進め方 | まず2体を試しに作って見てもらい、雰囲気が決まってから残りを作る |

**2Dの絵は、まだ仮のもの**（動物の絵文字12種を丸い枠に入れたもの。ポーズは傾き・汗・おばけの印で表す）。画像生成の費用をかけない方針のあいだは、この仮の絵で遊ぶ。絵を作ったら `src/modes/fate/charas.tsx` の中身を差し替える（ほかの画面は変えなくてよい）。

### 11.9 順位

- 勝ち残った順で順位を付ける。最後の1人が1位、そのあとは落ちるのが遅かった順。同じ問題で落ちた人は同じ順位
- 得点は使わない（このモードでは「最後まで残った」ことが一番の見せ場のため）
- 最終結果の画面では、順位と、それぞれが何問目で落ちたかを出す ［提案］

### 11.10 通信

- 位置が変わるたびにホストへ送り、ホストが全員に配る。10人までなら通信量は問題にならない
- 締め切りの判定はホストの時計で行う（4.4.4 と同じ）。通信の遅れで締め切りの直前に動いた分が届かないことがあるため、ホストは締め切りの少しあとに締める ［提案］

### 11.11 実装で決めた細部

仕様に書いていなかったところを、実装のときに次のように決めた。

| 項目 | 決めたこと | 理由 |
|---|---|---|
| 締め切りの猶予 | 0.5秒（今のモードは1.5秒） | 制限時間が5秒のこともあるので、猶予が長いと締め切り後に動けてしまう。参加者の画面では、0秒になった時点で動けなくする |
| 発表を見せる時間 | 5秒 ※暫定値 | 床が開く → 落ちる → 名前を読む、に足りる長さ。テストプレイで調整する |
| 同じ問題を複数の人が持ってきた | 持ってきた全員を「作った人」として、自動でセーフにする | 全員が答えを知っているため |
| 「全員が不正解」の数え方 | 作った人とゴーストを除いた、生き残りの全員が不正解のとき | 作った人以外が全員落ちると、自分の問題で勝ち残れてしまうため |
| 切断中の人 | 真ん中に立ったまま扱いになり、次の締め切りで落ちる（全員不正解なら救済される） | 特別な決まりを増やさないため |
| 一時停止 | ホストが、出題中でも発表中でも止められる。再開すると、残り時間から続く | 11.5 の「一時停止」を、出題中にも使えるようにした |
| 画面 | 参加者の一覧と得点は出さない（舞台の上に全員がいるため）。生き残りの人数を出す | — |
| 音 | 出題・発表・結果で BGM を変えない（並び替えの曲のまま）。効果音「床が開いて落ちる」「助かった」を足した | 数秒ごとに曲が変わると落ち着かないため |
| 操作 | 左右の答え・床をタップ。キーボードの ← → でも動ける | — |

### 11.12 3D表示

舞台を3Dでも見られるようにする。2D表示はそのまま残す。

| 項目 | 仕様 | 理由 |
|---|---|---|
| 切り替え | 舞台の下の「2D／3D」で、各自が自分の端末の表示を選ぶ（端末に保存。初期値は3D）。同じ部屋に2Dの人と3Dの人が混ざってよい | ルールと通信は同じで、描き方だけが違うため。古い端末で重い人は2Dにできる |
| 3Dにする範囲 | 舞台（左右の床・スタート台・キャラクター）だけ。問題文・答え・残り時間・結果画面は今のまま | 文字は今の画面の方が読みやすい |
| 視点 | 斜め上から見下ろす。動かせない | 全員の位置がひと目で分かるように |
| 床 | 厚みのある台。不正解の床は、2枚の扉が下に開く。正解の床は緑に光る。全員不正解のときは、開いてすぐ閉じる | 2Dと同じ決まりを立体で見せる |
| キャラクター | **アニメ調のデフォルメ**（おもちゃ風から作り替えた）。動物12種と人5種（2Dの絵文字と同じ並び）。決まりは4つ：①顔は絵で描く（大きな瞳・光・まつげ・ほっぺ。目や口を立体で作らない）②ふちに輪郭線 ③陰影はトゥーン調（3段階）④頭を身長の半分近くまで大きく、体と手足は小さく。髪は大きな房で、動物は耳としっぽでシルエットを描き分ける。足元の輪の色と名前の札で、人を見分ける | 「アニメ調のデフォルメに近づけたい」という要望から。1体を試作して方向を確かめてから広げた。形は球・円すい・円柱の組み合わせのまま（費用をかけない）。特定の作品のキャラクターや意匠は写さない |
| ポーズ | 立ち（ゆっくり弾む）／移動中（跳ねながら向かう）／落ちる（顔の絵が驚き顔に替わり、空中でじたばた → 回りながら穴へ）／ゴースト（半透明で白っぽく、浮かぶ） | 11.8 の4ポーズ |
| 操作 | 2Dと同じ（上の答えをタップ、床をタップ、← →） | — |
| 動きを減らす設定 | 揺れ・じたばた・回転を出さず、落ちる人は小さくなって消える | 8.2 と同じ配慮 |
| 3Dが使えない端末 | 自動で2D表示にする | WebGL が動かない環境があるため |
| 読み込み | 3Dの部品（three.js）は、3D表示を選んだ人だけが読み込む | 2Dの人の読み込みを重くしないため |
| 描画の軽さ（更新） | 1体を「体・輪郭線・顔の絵」の3回で描く（部品をまとめて1つの形にし、色は頂点ごとに持たせる）。輪郭線は、同じ形をもう一度描くので、三角形は1体あたり1万前後になる。影は光から計算せず、足元に丸い影を置く。目安は、10人のときに描画150回・30万三角形以下（スマホ向け） | 部品を1つずつ描いていたときは、10人で約450回になる見込みで、スマホには重かった。数字は `tests/fate.three.test.ts` で見張る |
