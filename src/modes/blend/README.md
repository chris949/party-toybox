# まぎれろ！

同じ見た目のキャラクターが大勢うろうろする舞台で、1体だけ人が動かす。どれが人かを当てるゲーム。

- 遊ぶ：https://chris949.github.io/party-toybox/ （ホストが、ロビーで「モード」を **まぎれろ！** にする）
- ゲーム集ぜんたいの説明・遊ぶ前の注意：[README](../../../README.md)・[docs/guide.md](../../../docs/guide.md)

## あそびかた

お題は使いません。

- 同じ見た目のキャラクターが、3Dの舞台を大勢うろうろします。**1体だけ、人（かくれる人）が動かしています**
- **かくれる人**：▼ が付いているのが自分です。床をタップすると、そこへ歩きます。時間内に、舞台に出る **ほし** を3つ集めてください。ほしの上にいる間だけ「ほしを取る」を押せます
- ほしを取った瞬間は、全員に見えます。ほかのキャラクターが集まるのを待ってから取るのがコツです
- **さがす人**：あやしい1体をタップして**狙い**（▼ が付きます）、「撃つ」を押します。**弾は1発**です（ホストがロビーで 1〜3発に変えられます）
- **当たったら、その場で終わり**。当てた人に +3点です
- 外すと、撃たれた1体はその場に倒れます（人ではなかった、と全員に分かります）
- かくれる人は、**ほしを3つ集めきる**か、**さがす人が全員、弾を使いきる**と、逃げ切りです。さがす人の人数ぶんの点がもらえます
- 全員が1回ずつかくれたら終わりです
- かくれる時間（30／45／60秒）・キャラクターの数（8／12／16体）・弾の数（1／2／3発）は、ホストがロビーで選べます
- 人数が少ないときは、ロビーで CPU を足せます

## 15. モード：まぎれろ！

### 15.1 概要

- 同じ見た目のキャラクターが、舞台を大勢うろうろする。そのうち **1体だけ、人（かくれる人）が動かしている**。ほかの全員（さがす人）が、どれが人かを見破って**撃つ**
- **盛り上がる瞬間**：「いま、ほしが消えた！ 乗ってたの誰！？」「そいつ、さっきから動きが人間くさい」「撃つ？ まだ待つ？」「うわ、外した…！」
- かくれる人には **仕事** がある：時間内に、舞台に出る **ほし** を3つ集める。ほしを取った瞬間は全員に見えるので、取るたびに疑われる
- さがす人の **弾は少ない**（初期値は1発）。撃てば、その場で結果が出る。「いつ撃つか」が駆け引きになる
- お題は使わない。人数は2〜10人（CPU の参加者を足せる）

### 15.2 ロビーの設定

| 設定 | 選べるもの | 理由 |
|---|---|---|
| かくれる時間 | **30／45（初期値）／60秒** | ほしを3つ集めるのに、急げば20秒ほど。人だかりを待つ余裕を足した |
| キャラクターの数 | **8／12（初期値）／16体** | 多いほど、かくれやすい。スマホでは少なめが見やすい |
| 弾の数 | **1（初期値）／2／3発** ［提案］ | さがす人1人あたりの数。さがす人が少ないとき（2〜3人で遊ぶとき）は、増やすと当てやすい |

### 15.3 1ラウンドの流れ

1. **よーい（3秒）**：全員が止まっている。かくれる人の画面にだけ、自分のキャラクターの上に ▼ が出る。この間は撃てない
2. **かくれる・さがす**（設定した時間）
   - CPU のキャラクターは、行き先を決めて歩く → 少し立ち止まる、をくり返す。ときどき（2割）、ほしのあたりへ行く（輪の外まで広がって集まる。輪の中をふさいで、かくれる人が乗れなくならないように）
   - **かくれる人**：床をタップすると、そこへ歩く。速さは CPU と同じ。ほしの上にいる間だけ「ほしを取る」ボタンを押せる（乗っただけでは取れない。**人だかりができるのを待ってから取る**、という駆け引きのため）
   - ほしを取ると、ほしが消えて、その場所から輪が広がる（全員に見える）。少しして、次のほしが別の場所に出る
   - CPU がほしに乗っても、ほしは消えない
   - **さがす人**：あやしい1体をタップして**狙う**（自分にだけ、その1体に ▼ と赤い輪が付く。何度でも狙い直せる）。「撃つ」ボタンを押すと、狙っている1体を撃つ
     - 狙うと撃つを分ける理由：弾が少ないので、押し間違いで撃ってしまうのを防ぐ（遊んだ感想：重なっていて、意図と違う1体を選んでしまった）
   - **当たった**（人が動かしている1体だった）：その場で発表へ進む
   - **外した**：撃たれた1体は、その場に倒れて動かなくなる（全員に見える。人ではないと分かるので、ほかの人の手がかりになる）。倒れた1体は、もう撃てない
3. **ラウンドが終わるとき**（どれか早いもの）

   | 終わり方 | 結果 |
   |---|---|
   | さがす人が当てた | 当てた人の勝ち |
   | かくれる人が、ほしを3つ集めきった | かくれる人の逃げ切り |
   | さがす人の全員が、弾を使いきった | かくれる人の逃げ切り |
   | 時間切れ（ホストの「時間を待たずに発表する」も同じ） | 引き分け（どちらにも点なし） |

4. **発表**：人が動かしていた1体に、名前の札と ▼ が出て、跳ねる。誰が撃って、当たったか外れたかを並べる。ホストの「次のラウンドへ」で次へ

- かくれる人は、順番に交代する。**全員が1回ずつかくれたら終わり**
- かくれる人が切断したら、その回は流れる（点なし）
- 経緯：はじめは「何度でも選び直せて、判定は発表のとき」だった。当てても何も起きず、ほしを集めきるまで続くので、テンポが悪かった（遊んだ感想）。撃った瞬間に結果が出る形に変えた

### 15.4 点

| だれ | 点 |
|---|---|
| さがす人 | 当てた1人に **+3点**（当たった時点で終わるので、もらえるのは1人だけ）［提案］ |
| かくれる人 | **逃げ切ったとき**（ほしを3つ集めきった／全員が弾を使いきった）、さがす人の人数ぶんの点。時間切れは0点 |

- 「じっとしていれば安全」にしないため、時間切れでは、かくれる人に点が入らない
- さがす人が誰も撃たないと、かくれる人は、ほしを集めきるしかない。ほしを取るたびに手がかりが出るので、撃たずに待つほど、さがす人が有利になる。ただし、3つ目を取られたら終わり

### 15.5 体が重ならない決まり

- キャラクターどうしは、一定の近さ（0.85。体1つぶんほど）より近づかない。**人が動かす1体にも、同じ決まりをかける**（動きの違いで、人だと分からないようにする）
- 進む先に誰かがいたら、よけて回りこむ。回りこめないときは、その場で止まる
- 倒れた1体も、場所をふさぐ
- ほしの輪（半径1.05）は、この近さより広い。真ん中に誰かが立っていても、となりに立てば、ほしに乗れる。輪の中には、6〜7体まで入れる（人だかりを待って取る、という駆け引きは残す）
- 理由：遊んだ感想「キャラクターが重なって、選びづらい」。3Dの舞台では、体が離れていても、手前の1体が奥の1体を画面の上で隠すことがある。そのため、狙う → 撃つ の2段階（15.3）と合わせて使う

### 15.6 通信と、見せる情報

- **ホストが正**。ホストが、全員ぶんの位置を0.2秒ごとに進めて、全員に送る。画面は、届いた位置のあいだをなめらかにつなぐ
- **人が動かす1体も、CPU の1体も、同じ形で送る**。どれが人かは、かくれている本人にだけ送り、ほかの人には発表まで送らない（開発者ツールで見ても分からないようにする）
- かくれる人の操作は「行き先」だけを送る（押している間ずっと送る、という作りにしない。通信が軽く、動きも CPU と同じ形になる）
- 位置は、100倍した整数で送る
- **狙い**は、自分の画面の中だけのもので、送らない。**撃った**ことだけを送る。誰がどれを撃ったか・倒れている1体・各自の残りの弾は、全員に見せる

### 15.7 見た目

- 3Dの舞台。キャラクターは、運命の二者択一のもの（動物12種・アニメ風の人5種）から、ラウンドごとに1種類をランダムに選び、全員を同じ見た目・同じ色にする
- 歩いている間は小さく跳ねる。進む方を向く
- 自分が狙っている1体に、▼ と、足元の赤い輪（自分にだけ見える）
- 撃たれた場所から、赤い輪が広がる。外れなら、その1体が倒れる
- 3D（WebGL）が使えない端末では、舞台を表示できない旨を出す（2Dの表示は用意していない）

### 15.8 CPU の参加者

- **さがす側**：時間のどこかで撃つ（弾の数だけ）。4回に1回は当てる。それ以外は、倒れていない1体からでたらめに撃つ
- **かくれる側**：ルールが代わりに動かす。ほしへ向かいやすく（7割）、乗ったらすぐ取る
