## 15. モード：まぎれろ！（v0.25。決定：2026-11-12）

壁打ちで決めたのは「3Dの舞台を、同じ見た目のキャラクターが大勢うろうろする。1体だけ人が動かしていて、ほかの全員が、どれが人かを当てる」まで。**それ以外の細部は、すべて Claude が補った［提案］**（ほし・点の付け方・時間・操作のしかた）。遊んでから直す前提。

### 15.1 概要

- 同じ見た目のキャラクターが、舞台を大勢うろうろする。そのうち **1体だけ、人（かくれる人）が動かしている**。ほかの全員（さがす人）が、どれが人かを当てる
- **盛り上がる瞬間**：「いま、ほしが消えた！ 乗ってたの誰！？」「そいつ、さっきから動きが人間くさい」「え、ずっと隣にいたのに…」
- かくれる人には **仕事** がある：時間内に、舞台に出る **ほし** を3つ集める。ほしを取った瞬間は全員に見えるので、取るたびに疑われる
- お題は使わない。人数は2〜10人（CPU の参加者を足せる）

### 15.2 ロビーの設定

| 設定 | 選べるもの | 理由 |
|---|---|---|
| かくれる時間 | **30／45（初期値）／60秒** | ほしを3つ集めるのに、急げば20秒ほど。人だかりを待つ余裕を足した |
| キャラクターの数 | **8／12（初期値）／16体** | 多いほど、かくれやすい。スマホでは少なめが見やすい |

### 15.3 1ラウンドの流れ

1. **よーい（3秒）**：全員が止まっている。かくれる人の画面にだけ、自分のキャラクターの上に ▼ が出る
2. **かくれる・さがす**（設定した時間）
   - CPU のキャラクターは、行き先を決めて歩く → 少し立ち止まる、をくり返す。ときどき（3割）、ほしの上へ行く
   - **かくれる人**：床をタップすると、そこへ歩く。速さは CPU と同じ。ほしの上にいる間だけ「ほしを取る」ボタンを押せる（乗っただけでは取れない。**人だかりができるのを待ってから取る**、という駆け引きのため）
   - ほしを取ると、ほしが消えて、その場所から輪が広がる（全員に見える）。少しして、次のほしが別の場所に出る。3つ集めたら、もう出ない
   - CPU がほしに乗っても、ほしは消えない
   - **さがす人**：あやしい1体をタップして選ぶ。時間内は、何度でも選び直せる。誰がどれを選んでいるかは、発表まで見えない（選んだ人数だけ見える）
3. **発表**：人が動かしていた1体に、名前の札と ▼ が出て、跳ねる。誰が当てたかを並べる。ホストの「次のラウンドへ」で次へ

- かくれる人は、順番に交代する。**全員が1回ずつかくれたら終わり**
- ホストは「時間を待たずに発表する」で、先に進められる
- かくれる人が切断したら、その回は流れる（点なし）

### 15.4 点

| だれ | 点 |
|---|---|
| さがす人 | 当てたら **+2点** |
| かくれる人 | **ほしを3つ集めきったときだけ**、だませた人数ぶんの点（選ばなかった人も、だまされた人に数える）。集めきれなければ0点 |

- 「じっとしていれば安全」にしないため、ほしを集めきらないと点が入らない形にした

### 15.5 通信と、見せる情報

- **ホストが正**。ホストが、全員ぶんの位置を0.2秒ごとに進めて、全員に送る。画面は、届いた位置のあいだをなめらかにつなぐ
- **人が動かす1体も、CPU の1体も、同じ形で送る**。どれが人かは、かくれている本人にだけ送り、ほかの人には発表まで送らない（開発者ツールで見ても分からないようにする）
- かくれる人の操作は「行き先」だけを送る（押している間ずっと送る、という作りにしない。通信が軽く、動きも CPU と同じ形になる）
- 位置は、100倍した整数で送る

### 15.6 見た目

- 3Dの舞台。キャラクターは、運命の二者択一のもの（動物12種・アニメ風の人5種）から、ラウンドごとに1種類をランダムに選び、全員を同じ見た目・同じ色にする
- 歩いている間は小さく跳ねる。進む方を向く
- 自分が選んでいる1体の足元に、赤い輪（自分にだけ見える）
- 3D（WebGL）が使えない端末では、舞台を表示できない旨を出す（2Dの表示は用意していない）

### 15.7 CPU の参加者

- **さがす側**：時間のどこかで1体を選ぶ。4回に1回は当てる（かくれる人の点が、CPU の数だけで決まらないようにする）
- **かくれる側**：ルールが代わりに動かす。ほしへ向かいやすく（7割）、乗ったらすぐ取る

### 15.8 未決・あとで足すもの

| # | 論点 | 現状 |
|---|---|---|
| M1 | 点の付け方 | 当てたら+2、かくれる人はだませた人数ぶん。人数が多いと、かくれる人の点が大きくなる。遊んで決める |
| M2 | さがす人が、早く当てるほど高い点にするか | しない（時間内は選び直せる）。「早押し」にすると、通話で相談する楽しさが減るため |
| M3 | CPU の動きの種類 | 歩く・止まるだけ。人間くさい動き（うろうろ、引き返す）を CPU にも混ぜると、難しくできる |
| M4 | 2Dの表示 | なし。3D が使えない端末が多ければ、上から見た図を足す |
| M5 | かくれる CPU の強さ | ほしへまっすぐ行ってすぐ取るので、見つけやすい |
