## 14. モード：ワードブーケ（v0.24。決定：2026-11-12）

壁打ちで決めた内容（2026-11-12）。**［提案］** と付けたところは、壁打ちで話していない細部を Claude が補ったもの。

### 14.1 概要

- お題（例：プロポーズの言葉）に対して、配られた**言葉のカード**を並べて、ひとことを作る。**親**が、いちばん刺さったものを選ぶ
- **盛り上がる瞬間**：「その言葉をそこに置く！？」「なんでそれで口説けると思った（笑）」。欲しい言葉が手札にないから、無理やりな文になる。親が声に出して読み上げると、通話がそのまま発表会になる
- 言葉を束ねて贈る、という意味で「ワードブーケ」
- 配られた言葉を並べて文を作り、親が選ぶ、という遊び方は昔からある形。カードの中身・名前・見た目は、すべてオリジナル

### 14.2 ロビーの設定

| 設定 | 選べるもの | 理由 |
|---|---|---|
| 作る時間 | **45／60（初期値）／90秒** ［提案］ | 並べるだけなので、ティアリストの並び替えと同じくらい |
| 終わり方 | **全員が親を1回（初期値）／3点先取／5点先取** | 壁打ちでは「決められた数を取ったら勝ち」。人数で長さがぶれないよう、初期値は「全員が親を1回」にした ［初期値は提案］ |

| 手札の枚数 | **10／14（初期値）／20／30枚**（v0.30） | 多いほど、狙った文を作りやすい。少ないほど、無理やりな文になる |
| 言葉 | **プリセットと混ぜる（初期値）／持ち寄りだけ**（v0.30） | みんなが持ってきた言葉を、どう使うか（14.3） |

- CPU の参加者を足せる（共通の仕様 2.1）。CPU は、手札からでたらめに文を作り、親のときはランダムに選ぶ。2人だと選ぶ候補が1つしかないので、少人数のときは CPU を足すのがおすすめ

### 14.3 お題と言葉

- **お題**：「お題の設定」に「ワードブーケ」のタブ。1つ最大60文字。同梱のサンプルは24個。その回の**親が持ってきたお題**から1つ使い、持ってきていなければサンプルを使う。同じお題は、1ゲームに1回まで ［親のお題を使うのは提案］
- **言葉のカード**：同梱のプリセットだけを使う（各自が言葉を作るのは大変なため。決定：2026-11-12）。名詞・言い回し・修飾の3種類で、合わせて約300語。甘い言葉・日常の言葉・場違いな言葉を混ぜてある
- **言葉の持ち寄り**（v0.30。決定：2026-11-14。「プリセットだけだと味気ない」という声）：「お題の設定」のワードブーケのタブに「言葉」の一覧がある。1語ずつ足す・消す。1語は12文字まで、1人60語まで。入れた言葉は、すべて持っていく
  - **プリセットと混ぜる**：手札の半分までを、みんなが持ってきた言葉から配る。残りはプリセット ［割合は提案］
  - **持ち寄りだけ**：手札を、みんなが持ってきた言葉だけで配る。足りない分は、プリセットで埋める（始められない、にはしない）［提案］
  - 持ってきた言葉は、全員ぶんを1つにまとめて配る（誰の言葉が誰に行くかは、決まっていない）
- **手札**：ロビーで決めた枚数（初期値14枚）。プリセットの分は、名詞・言い回し・修飾を 6：5：3 の割合で配る ［提案。文になりやすいよう、種類を混ぜる］。1ラウンドに1回だけ、手札をまるごと**引き直せる**
- **助詞など**（は・が・を・に・の・と・で・も・！・？ など22種）は、手札と別に、何度でも使える

### 14.4 1ラウンドの流れ

1. **作る**：親以外の全員が、同時に作る。カードと助詞をタップして並べる（並べたものをタップすると外れる。「ぜんぶ外す」で、最初からやり直せる）。合わせて12個まで。手札のカードを1枚以上使う
   - 全員が提出すると、時間を待たずに次へ。時間切れのときは、並べていた分で提出する（何も並べていなければ、提出なし）
   - 親は、その間、誰が提出したかだけ見える
2. **選ぶ**：全員の作品を、**作った人の名前と一緒に**並べる（誰が作ったか込みで面白い。決定：2026-11-12）。親が、声に出して読み上げ、いちばん刺さったものを1つ選ぶ
   - 親が切断中などで選べないときは、ホストが「選ばずに進める」で先に進められる（その回は点なし）
3. **発表**：選ばれた作品を大きく見せる。選ばれた人に **1点**。ホストの「次のラウンドへ」で次へ。親は、順番に交代する

### 14.5 終わり方

- 「全員が親を1回」：人数ぶんのラウンドで終わり。点が多い順に順位を付ける
- 「3点先取」「5点先取」：誰かがその点に届いたら終わり（長くなりすぎないよう、40ラウンドで打ち切る ［提案］）
- 最終結果は、ほかのモードと同じ（順位、1位に紙吹雪、ホストが「ロビーに戻る」）
