# ブラインドブラフ

自分のカードだけ見えないトランプ遊び。通話でだまし合う。

- 遊ぶ：https://chris949.github.io/party-toybox/ （ホストが、ロビーで「モード」を **ブラインドブラフ** にする）
- ゲーム集ぜんたいの説明・遊ぶ前の注意：[README](../../../README.md)・[docs/guide.md](../../../docs/guide.md)

## あそびかた

お題は使いません。

- 1人に1枚、1〜13の数字のカードが配られます。**自分のカードだけ見えず、ほかの全員のカードは見えます**
- 制限時間のあいだ、通話でしゃべってください。本当のことを言っても、嘘を言ってもかまいません
- 「**勝負**」か「**降りる**」を選びます。選んだら変えられません
- 降りると −1点。勝負して負けると −2点。勝負した中でいちばん強い人が、みんなの払った点をもらいます
- **いちばん強いカードなのに降りると、さらに −2点**
- 全員10点から始めて、8ラウンド。点が多い人の勝ちです
- 人数が少ないときは、ロビーで CPU を足せます

## 13. モード：ブラインドブラフ

### 13.1 概要

- 1人に1枚、数字のカードが配られる。**自分のカードだけ見えず、ほかの全員のカードは見える**。その状態で、「勝負」するか「降りる」かを決める
- **盛り上がる瞬間**：通話でのだまし合い（「お前のそれ、絶対降りた方がいいって！」「嘘つくな！」）。カードをめくった瞬間（「それで降りたの！？」「13持ってたのかよ！」）
- 昔からあるトランプ遊びが元。名前はオリジナルにした
- お題は使わない（「お題の設定」に、このモードのタブはない）

### 13.2 ロビーの設定

- **しゃべる時間**：ホストが **20／30（初期値）／45秒** から選ぶ ［時間は提案。遊んで調整する］
- CPU の参加者を足せる（共通の仕様 2.1）。CPU は、見えているカードから、勝負か降りるかを決める

### 13.3 1ラウンドの流れ

1. **配る**：1〜13 の数字のカードを、参加者に1枚ずつ配る。同じ数字は配らない（引き分けをなくすため）。マークは使わない ［提案］
2. **しゃべって決める**：全員のカードが、本人以外に見える。制限時間のあいだ、通話で本当のことも嘘も言ってよい。各自が「勝負」か「降りる」を選ぶ
   - 誰が選び終わったかは見えるが、何を選んだかは発表まで見えない
   - 選んだら変えられない。全員が選ぶと、時間を待たずに発表へ進む
   - 時間切れ・切断中の人は「降りる」になる ［提案］
   - ホストは「未提出の人を待たずに進める」で先に進められる
3. **発表**：全員のカードと選んだものを出し、点を動かす。ホストの「次のラウンドへ」で次へ

### 13.4 点（チップ）

全員、**10点**を持って始める ［提案］。脱落はない（最後まで全員がしゃべり続けられるように）。

| 選んだもの | 結果 | 点 |
|---|---|---|
| 降りる | — | **−1** |
| 降りる | しかも、その回の全員の中でいちばん強いカードだった | さらに **−2**（「それで降りたの！？」） |
| 勝負 | 勝負した人の中でいちばん強い | **負けた人・降りた人が払った点を、全部もらう** |
| 勝負 | 負け | **−2** |

- 全員が降りたら、点は動かない ［提案］
- 勝負したのが1人だけなら、その人が、降りた人の払った点をもらう
- 持ち点より多くは払わない（0点より下にはならない） ［提案］

### 13.5 終わり方

- **8ラウンド**で終わり。点が多い順に順位を付ける ［ラウンド数は提案。1ラウンド1分ほどで、10分以内に終わる長さ］
- 最終結果は、ほかのモードと同じ（順位、1位に紙吹雪、ホストが「ロビーに戻る」）

### 13.6 画面

- **しゃべっている間**：全員のキャラクターが、頭の上にカードを掲げて並ぶ。自分のカードだけ「？」。下に「勝負」「降りる」のボタン
- **発表**：自分のカードがめくれる。勝った人・強いのに降りた人が分かるように印を付け、各自の点の増減を出す
- キャラクターは2Dの絵（絵文字）で出す。3Dのキャラクターがカードを掲げる見せ方は、あとで足す ［提案。まずルールの面白さを確かめるため］
