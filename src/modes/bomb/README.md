# 爆弾まわし

いつ爆発するか分からない爆弾を回すゲーム。回ってきたら、自分のお題の正解を1つ当てて渡す。

- 遊ぶ：https://chris949.github.io/party-toybox/ （ホストが、ロビーで「モード」を **爆弾まわし** にする）
- ゲーム集ぜんたいの説明・遊ぶ前の注意：[README](../../../README.md)・[docs/guide.md](../../../docs/guide.md)

## あそびかた

お題は、**セレクトファイブのお題**（みんなが持ってきたものと、サンプル）を使います。

- 誰か1人が爆弾を持ちます。**いつ爆発するかは、誰にも分かりません**
- 1人に1つ、別々のお題が配られます。爆弾が回ってきたら、**自分のお題の正解を1つ当てて**、渡す相手のボタンを押します
- 答え方は、ホストがロビーで選びます
  - **選択式**：正解だと思う選択肢をタップします
  - **入力式**：正解だと思う選択肢の文字を、打ち込みます（ひらがなでも、カタカナでも通ります）
- はずれ（ダミー）を選ぶと、2秒間、操作できません。一度当てた正解は、もう使えません
- 持っている人のお題と選択肢は、全員に見えます。通話で教えるかどうかは、自由です
- 時間がたつほど、カチカチが速くなり、爆弾が激しく揺れ、画面が赤くなっていきます
- 爆発したとき、持っていた人以外の全員に1点。決めた回数（3／5／8回）だけ爆発したら終わりです
- 導火線の長さ（みじかめ／ふつう／ながめ）は、ホストがロビーで選べます
- 人数が少ないときは、ロビーで CPU を足せます

## 16. モード：爆弾まわし

### 16.1 概要

- いつ爆発するか分からない爆弾を、みんなで回す。回ってきたら、**自分のお題の正解を1つ当てて**、誰かに渡す。爆発したときに持っていた人の負け
- **盛り上がる瞬間**：「早く早く早く！」「それダミーだって！」「なんで俺に返すんだよ！」
- 人数は2〜10人（CPU の参加者を足せる）

### 16.2 ロビーの設定

| 設定 | 選べるもの | 理由 |
|---|---|---|
| 答え方 | **選択式（初期値）／入力式** | 選択式：選択肢をタップする。入力式：選択肢の文字を打ち込む（緊迫感が出る）。スマホで漢字を打つのは大変なので、初期値は選択式 ［初期値は提案］ |
| 爆発の回数 | **3／5（初期値）／8回** ［提案］ | 1回が20〜45秒なので、5回で5分ほど |
| 導火線 | **みじかめ（15〜30秒）／ふつう（20〜45秒。初期値）／ながめ（30〜70秒）** ［提案］ | 幅の中から、毎回ランダムに決める |

### 16.3 お題

- **セレクトファイブのお題**（正解とダミーが混ざった選択肢）を使う。みんなが持ってきたものと、同梱のサンプル
- ラウンドの始めに、**1人に1つ、別々のお題**を配る。自分が作ったお題は、なるべく自分に当たらないようにする（ほかに配れるお題がないときだけ当たる）［提案］
- 選択肢の数と、ダミーの数は、セレクトファイブと同じ決まりで抜き出す
- 自分のお題の正解を使い切ったら、その人に新しいお題を配る
- お題が足りないときは、同じお題をもう一度使う

### 16.4 1ラウンドの流れ

1. **火がつく**：誰か1人が爆弾を持つ（最初はランダム。2回目からは、前に爆発した人）
2. **まわす**：持っている人の画面に、その人のお題と選択肢が出る
   - **選択式**：正解だと思う選択肢をタップする
   - **入力式**：正解だと思う選択肢の文字を、打ち込む。見えている選択肢のどれかと合えば、それを選んだことになる（ひらがな・カタカナ・英字の大文字小文字・空白のちがいは、同じとみなす）。どれとも合わないときは、何も起きない
   - **正解**：渡す相手のボタンが押せるようになる。**渡す相手は、自分で選べる**
   - **はずれ（ダミー）**：その選択肢に ✕ が付き、**2秒間、操作できない** ［提案］
   - 一度当てた正解は、同じラウンドの中では、もう使えない
   - 持っている人のお題と選択肢、当たり・はずれは、**全員に見える**（通話で「それ！」と教えてよい。教えるかどうかも駆け引き）［提案］
   - 持っている人が切断したら、爆弾は、つながっている誰かに飛ぶ
3. **爆発**：持っていた人以外の全員に **1点**。持っていた人のお題の正解を見せる。ホストの「次のラウンドへ」で次へ

- 決めた回数だけ爆発したら終わり。点が多い順に順位を付ける

### 16.5 ハラハラの出し方

- 爆発の時刻は、ホストだけが知っている。参加者には **導火線の燃え具合を4段階**（半分・4分の3・9割を過ぎるたびに1段）で送るだけ
- 段が進むたびに：カチカチの音が速くなる／爆弾の揺れが速くなる／背景が黄色 → オレンジ → 赤に変わる
- 3段目から：画面のふちが赤く点滅し、BGM が速くなる（残りわずかの演出を使う）
- 爆発：爆弾が 💥 に変わり、画面が揺れ、音が鳴る
- 自分が持っている間は、カードのふちが赤くなる

### 16.6 見せる情報

- どの選択肢が正解かは、選ぶまで送らない（選んだものの当たり・はずれだけを送る）。爆発したら、持っていた人のお題の正解を全員に送る
- まだ持っていない人のお題は、本人にも送らない（回ってきて初めて見える）

### 16.7 CPU の参加者

- 爆弾を持ったら、1〜3秒考えて選ぶ（7割で正解）。当てたら、ランダムな相手に渡す

### 16.8 未決・あとで足すもの

| # | 論点 | 現状 |
|---|---|---|
| B1 | 入力式で、選択肢を見せずに答える | しない（選択肢は見せる）。見せない形にするには、「都道府県」のように答えが数えきれるお題のデータが別に要る |
| B2 | 持っている人のお題を、ほかの人に見せるか | 見せる。教え合いで緊張がゆるむなら、本人だけに見せる形にする |
| B3 | 点の付け方 | 爆発した人以外に1点。ライフ制（爆発で1つ減り、なくなったら脱落）にするか、遊んで決める |
| B4 | 渡す相手 | 自分で選ぶ。同じ2人で返し合い続けられるので、「直前にくれた人には返せない」を足すかどうか |
| B5 | 爆発の音 | 専用の音がない（落ちる音を使っている） |
| B6 | はずれの罰 | 2秒間、操作できない。短い・長いは、遊んで決める |
