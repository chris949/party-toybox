## 16. モード：爆弾まわし（v0.26。決定：2026-11-12）

壁打ちで決めたのは「いつ爆発するか分からない爆弾を回す。回すには、お題に合う言葉を1つ入力する。ハラハラは3Dでなく、導火線・音・ふちの点滅で出す」まで。**［提案］** と付けたところは、Claude が補った細部。

### 16.1 概要

- いつ爆発するか分からない爆弾を、みんなで回す。回ってきたら、**お題に合う言葉を1つ入れて、誰かに渡す**。爆発したときに持っていた人の負け
- **盛り上がる瞬間**：「早く早く早く！」「それもう出た！」「なんで俺に返すんだよ！」
- 言葉がお題に合っているかは、**機械では判定しない**。通話で「それはナシだろ（笑）」とツッコむのが遊びのうち ［提案］
- 人数は2〜10人（CPU の参加者を足せる）

### 16.2 ロビーの設定

| 設定 | 選べるもの | 理由 |
|---|---|---|
| 爆発の回数 | **3／5（初期値）／8回** ［提案］ | 1回が20〜45秒なので、5回で5分ほど |
| 導火線 | **みじかめ（15〜30秒）／ふつう（20〜45秒。初期値）／ながめ（30〜70秒）** ［提案］ | 幅の中から、毎回ランダムに決める。人数が多いときは長めが合う |

### 16.3 お題

- 同梱のお題（32個）から、ランダムに1つ。同じお題は、1ゲームに1回まで。すべてオリジナル
- 各自がお題を作って持ち寄る機能は、まだない ［提案。16.7 の B1］

### 16.4 1ラウンドの流れ

1. **火がつく**：お題が出て、誰か1人が爆弾を持つ（最初はランダム。2回目からは、前に爆発した人）
2. **まわす**：持っている人が、言葉を1つ入れて、渡す相手のボタンを押す。**渡す相手は、自分で選べる** ［提案。順番に回すより、「なんで俺に」が生まれる］
   - 相手が1人だけのときは、Enter キーでも渡せる
   - **同じ言葉は、もう使えない**（ひらがな・カタカナのちがいは、同じとみなす）。言葉は20文字まで
   - 出た言葉は、言った人の名前と一緒に、全員に見える
   - 持っている人が切断したら、爆弾は、つながっている誰かに飛ぶ
3. **爆発**：持っていた人以外の全員に **1点** ［提案］。ホストの「次のラウンドへ」で次へ

- 決めた回数だけ爆発したら終わり。点が多い順に順位を付ける

### 16.5 ハラハラの出し方

- 爆発の時刻は、ホストだけが知っている。参加者には **導火線の燃え具合を4段階**（半分・4分の3・9割を過ぎるたびに1段）で送るだけ
- 段が進むたびに：カチカチの音が速くなる／爆弾の揺れが速くなる／背景が黄色 → オレンジ → 赤に変わる
- 3段目から：画面のふちが赤く点滅し、BGM が速くなる（残りわずかの演出を使う）
- 爆発：爆弾が 💥 に変わり、画面が揺れ、音が鳴る
- 自分が持っている間は、カードのふちが赤くなる
- 3Dは使わない（決定：2026-11-12）

### 16.6 CPU の参加者

- 爆弾を持ったら、1.5〜5秒考えて、お題の例（1つのお題に8つ）からまだ出ていない言葉を言い、ランダムな相手に渡す

### 16.7 未決・あとで足すもの

| # | 論点 | 現状 |
|---|---|---|
| B1 | お題の持ち寄り | なし（同梱のみ）。ワードブーケと同じ形（1行のお題）で足せる |
| B2 | 「それはナシ」の扱い | 機械では判定しない。ホストが言葉を取り消して、爆弾を戻すボタンを足すかどうか |
| B3 | 点の付け方 | 爆発した人以外に1点。ライフ制（爆発で1つ減り、なくなったら脱落）にするか、遊んで決める |
| B4 | 渡す相手 | 自分で選ぶ。同じ2人で返し合い続けられるので、「直前にくれた人には返せない」を足すかどうか |
| B5 | 爆発の音 | 専用の音がない（落ちる音を使っている） |
