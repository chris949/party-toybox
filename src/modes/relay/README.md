# スタンプ伝言

絵と言葉の伝言ゲーム。スタンプを置いて絵にするので、絵が苦手でも遊べる。

- 遊ぶ：https://chris949.github.io/party-toybox/ （ホストが、ロビーで「モード」を **スタンプ伝言** にする）
- ゲーム集ぜんたいの説明・遊ぶ前の注意：[README](../../../README.md)・[docs/guide.md](../../../docs/guide.md)

## あそびかた

お題は、同梱のもの（90個）を使います。

- 1人に1つ、お題の言葉が配られます。それを **スタンプ（絵文字）だけで絵にして**、隣の人に回します
- 絵は、下の一覧からスタンプを選んで、指で動かして作ります。大きさ・向きも変えられます（1枚に15個まで）
- 次の人は、絵だけを見て、**何を表しているかを言葉で答えます**。その次の人は、その言葉をまた絵にします
- 全部回ったら、紙を1枚ずつめくって、どう伝わったかをみんなで見ます
- 最後の答えが最初のお題と合っていたら、その紙に関わった全員に +1点（点はおまけです）
- 絵を作る時間（45／60／90秒）は、ホストがロビーで選べます
- 人数が少ないときは、ロビーで CPU を足せます（CPU の絵と答えは、でたらめです）

## 17. モード：スタンプ伝言

### 17.1 概要

- お題を **スタンプだけで絵にして** 隣へ回す → 次の人は絵だけを見て **言葉で答える** → その次の人は、その言葉をまた絵にする…と交互に回す。最後に、どう伝わったかを全員で見る
- **盛り上がる瞬間**：「なんで『病院』が『朝ごはん』になるんだよ（笑）」「この絵、誰！？」
- 絵と言葉を交互に回す伝言ゲームは、昔からある遊び方。スタンプで絵を作る形・名前・見た目は、すべてオリジナル
- 人数は2〜10人（CPU の参加者を足せる）

### 17.2 ロビーの設定

| 設定 | 選べるもの | 理由 |
|---|---|---|
| 絵を作る時間 | **45／60（初期値）／90秒** ［提案］ | スタンプを選んで置くだけなので、線を描くより短くて済む |

- 言葉で答える時間は、30秒で固定 ［提案］
- 1枚の紙が回る回数は、**人数と同じ（上限6回）** ［提案］。同じ人が同じ紙を2回持たないようにするため。2人なら「絵 → 答え」の2回、3人なら「絵 → 答え → 絵」の3回

### 17.3 スタンプとお題

- **スタンプ**：どの端末にも入っている **絵文字** を使う（約210個。ひと・いきもの・たべもの・もの・しぜん・きごう の6種類）［提案］
  - 絵の部品を同梱しなくて済み、通信も「どれを・どこに・大きさ・向き」だけで軽い
  - 文字・数字・国旗の絵文字は入れない（答えをそのまま書けないようにする）
  - 絵文字の見た目は、端末（iPhone・Android・Windows など）によって少し違う
- **絵の作り方**：下の一覧からスタンプを選ぶと、絵の真ん中あたりに出る。指でつかんで動かす。選んだスタンプは「小さく・大きく（5段階）」「回す（45度ずつ）」「消す」ができる。1枚に15個まで
- **お題**：同梱の90個から、1人に1つ、ちがうものを配る。すべてオリジナル（ふつうの言葉・場面・ことわざ）
- 各自がお題を作って持ち寄る機能は、まだない ［提案。17.6 の R1］

### 17.4 流れ

1. **まわす**：全員が同時に、手元の紙に1つ足す。全員が出すと、時間を待たずに、紙が隣へ回る
   - 見えるのは、手元の紙の **1つ前だけ**（最初の回は、お題の言葉。最初のお題は、最初の人にしか見えない）
   - 絵の番：1つも置いていない絵は出せない。答えの番：20文字まで
   - 時間切れのときは、作っていた分で出す。何もなければ、空の絵や「？？？」で埋める
   - ホストは「未提出の人を待たずに進める」で、先に進められる
2. **発表**：紙を1枚ずつ、ホストが「つぎをめくる」で上から順に見せる。最初のお題 → 絵 → 答え → …。誰が作ったかも出す。その紙の最初の人が、声に出して実況する
3. **最終結果**：点が多い順

### 17.5 点

- **最後の答えが、最初のお題と合っていたら、その紙に関わった全員に +1点** ［提案］（ひらがな・カタカナ・空白のちがいは、同じとみなす）
- 伝わらないほうが面白い遊びなので、点はおまけ。勝ち負けを強く出さない

### 17.6 未決・あとで足すもの

| # | 論点 | 現状 |
|---|---|---|
| R1 | お題の持ち寄り | なし（同梱のみ）。ワードブーケと同じ形（1行のお題）で足せる |
| R2 | 点の付け方 | 最後まで伝わったら全員に+1。「いちばん笑った絵」に全員で投票する形のほうが合うかもしれない。遊んで決める |
| R3 | スタンプの種類 | 絵文字。端末によって見た目が違う。そろえたいなら、自前の絵（SVG）を同梱する |
| R4 | スタンプの重なりの順番 | 置いた順（あとに置いたものが上）。入れ替えは、まだできない |
| R5 | 色を塗る・線を引く | なし。「地面」「空」などの背景を選べるようにする案 |
| R6 | 発表のあとに、作品を保存する | なし |
